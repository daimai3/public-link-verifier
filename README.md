# 공개 페이지 링크 확인 도구

출처 페이지 목록을 읽고 지정한 웹 주소로 연결되는 링크가 실제 HTML에 있는지 확인합니다. HTTP 상태, 최종 주소, `noindex` 표시와 링크의 `rel` 값도 CSV로 기록합니다.

베트남 여행 정보를 제공하는 [베트나비](https://vietnabi.com/)의 공개 링크 점검에도 이 도구를 사용합니다. 등록 신청이나 외부 서비스의 집계 수치만으로 링크가 게시되었다고 판단하지 않습니다.

## 사용 방법

파이썬 3.10 이상에서 추가 패키지 없이 실행할 수 있습니다. `sources.txt`에 확인할 출처 주소를 한 줄에 하나씩 적으세요.

```bash
python3 verify_links.py --target https://vietnabi.com/ --sources sources.txt --output results.csv
```

`exact_href`가 `True`이고 `http_status`가 `200`이며 `noindex`가 `False`인 행은 확인 시점에 대상 링크가 HTML에 있었습니다. 이 결과만으로 검색엔진의 색인이나 순위 효과가 입증되지는 않습니다. 자바스크립트가 실행된 뒤에만 나타나는 링크는 이 도구가 확인하지 못할 수 있습니다.

출처 사이트에 무리한 요청을 보내지 않도록 필요한 주소만 파일에 넣고, 사이트 이용 규칙을 지켜 주세요.
